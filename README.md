# 지에이솔루션 통합 시스템

대시보드·billing·lead-crm·report 4개를 하나로 합치는 새 앱입니다. 거래처(사업자)를 한 번만 등록하고 나머지가 모두 그걸 가져다 씁니다.

## 지금 들어 있는 것 (1단계)
- 로그인 하나, 권한 3가지(대표·팀장·직원)
- 거래처 → 브랜드(광고주) → 매체 계정, 업체 담당자, 다른 이름 목록, 변경 기록
- 화면: 로그인, 거래처 목록·검색, 거래처 등록, 거래처 상세(브랜드·계정·담당자 추가)

## 2단계: 바이럴
- 바이럴 건은 거래처를 골라서 입력. 대표자·사업자번호·주소·메일·사업자등록증은 거래처에서 자동으로 가져옴
- 마진(판매가-공급가) 자동 계산, 월별 합계
- 진행 상태 3가지 따로 관리: 고객 입금 / 세금계산서 / 협력사 결제. 밀린 건만 모아 보기
- 구글 시트 옮기기(대표·팀장): 시트를 읽어 미리보기 → 확인 후 옮기기. 같은 줄은 여러 번 옮겨도 한 건
  - 사업자번호가 틀린 줄(끌어 채우다 끝자리가 늘어난 경우 등)은 같은 업체의 올바른 번호로 연결하고 확인 목록에 표시
  - 칸이 한 칸 밀린 탭은 날짜 칸 위치로 맞춰 읽음

## 권한
- 직원: 모든 거래처 보기·등록, 본인 담당 거래처(또는 본인이 맡은 계정이 있는 거래처)만 수정
- 팀장: 모든 거래처 수정, 계정 담당자 지정, 변경 기록 보기
- 대표: 위 전부 + 삭제, 직원 추가·역할 변경
- 로그인하지 않은 사람은 아무것도 못 봄

## 실행
1. `.env.example`을 `.env.local`로 복사하고 새 Supabase 프로젝트 주소·공개 키를 넣습니다.
2. `supabase/migrations`의 SQL을 새 프로젝트에 적용합니다.
3. `npm install && npm run dev`

시험: `npm test` (시트 옮기기 계산 9개 + 실제 Postgres로 권한·데이터 규칙 48개)
